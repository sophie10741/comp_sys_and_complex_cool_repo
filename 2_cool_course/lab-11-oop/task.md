# Лабораторная работа №11

## Простые классы (C++)

---

## Вариант

Единый для всех студентов

---

## Цель работы

Научиться:
* создавать простые классы;
* работать с объектами;
* использовать поля и методы.

---

## Задание 1. Класс «Студент»

1. Создать класс `Student`.
2. Добавить поля:
   * имя;
   * возраст.
3. В `main`:
   * создать объект;
   * заполнить данные;
   * вывести на экран.

---

## Задание 2. Метод вывода

1. Добавить в класс метод `show()`.
2. Метод должен выводить данные студента.
3. Вызвать метод в `main`.

---

## Задание 3. Класс «Прямоугольник»

1. Создать класс `Rectangle`.
2. Поля:
   * длина;
   * ширина.
3. Найти и вывести площадь.

---

## Задание 4. Метод вычисления

1. Добавить метод `area()`.
2. Метод возвращает площадь.
3. Вывести результат через метод.

---

## Задание 5. Анализ ошибки

Дан код:

```cpp
class Test {
    int x;
};

int main() {
    Test t;
    t.x = 5;
}
```

* Найти ошибку.
* Исправить код.
* Объяснить, почему возникает ошибка.
