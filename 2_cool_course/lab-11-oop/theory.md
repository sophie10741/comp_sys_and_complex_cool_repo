## Что такое класс?

**Класс** — это шаблон (модель), по которому создаются объекты.

Пример из жизни:
* Класс: «Студент».
* Объекты: конкретные студенты.

---

## Что такое объект?

**Объект** — это экземпляр класса.

Пример:

```cpp
Student s1;
```

### Структура класса

```cpp
class ИмяКласса {
public:
    // поля (переменные)
    // методы (функции)
};
```

### Пример класса

```cpp
class Student {
public:
    string name;
    int age;
};
```

### Создание объекта

```cpp
Student s;
```

### Работа с полями

```cpp
s.name = "Ivan";
s.age = 18;
```

### Вывод данных

```cpp
cout << s.name << " " << s.age;
```

### Методы класса

Метод — это функция внутри класса.

```cpp
class Student {
public:
    string name;

    void show() {
        cout << name;
    }
};
```

### Вызов метода

```cpp
Student s;
s.name = "Ivan";
s.show();
```

### Типичные ошибки

* Забыли `;` после класса.
* Не указали `public:`.
* Ошибка при обращении к полям.
* Путают класс и объект.
