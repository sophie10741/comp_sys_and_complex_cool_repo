## Условный оператор `if`

Оператор `if` позволяет выполнять код **только при выполнении условия**.

Общий вид:

```cpp
if (условие) {
    // код выполняется, если условие истинно
}
Условие — это логическое выражение, результат которого:

true — истина;

false — ложь.

Пример использования if
cpp
Копировать код
int x;
cin >> x;

if (x > 0) {
    cout << "Число положительное";
}
Оператор if-else
Используется, когда нужно задать альтернативное действие.

cpp
Копировать код
if (x >= 0) {
    cout << "Число неотрицательное";
} else {
    cout << "Число отрицательное";
}

cpp

if (x > 0 && x < 10) {

Вложенные условия
cpp
Копировать код
if (x > 0) {
    if (x % 2 == 0) {
        cout << "Положительное чётное";
    } else {
        cout << "Положительное нечётное";
    }
}
Оператор выбора switch
Используется, если есть несколько вариантов одного значения.

cpp
Копировать код
int day;
cin >> day;

switch (day) {
    case 1:
        cout << "Понедельник";
        break;
    case 2:
        cout << "Вторник";
        break;
    case 3:
        cout << "Среда";
        break;
    default:
        cout << "Некорректный номер дня";
}
Особенности switch
Работает с целыми типами

Обязательно использовать break

default — необязателен, но желателен

Типичные ошибки
Использование = вместо ==

Отсутствие break в switch

Неверное условие

Отсутствие фигурных скобок
