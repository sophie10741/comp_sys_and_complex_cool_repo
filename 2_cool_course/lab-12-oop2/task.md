# Лабораторная работа №12

## Наследование (C++)

---

## Вариант

Единый для всех студентов

---

## Цель работы

Научиться:
* создавать иерархию классов;
* использовать наследование;
* работать с полями и методами базового класса.

---

## Задание 1. Базовый класс

1. Создать класс `Person`.
2. Поля:
   * имя;
   * возраст.
3. Добавить метод `show()`.

---

## Задание 2. Производный класс

1. Создать класс `Student`, наследующий `Person`.
2. Добавить поле:
   * группа.
3. В `main`:
   * создать объект;
   * заполнить все данные;
   * вывести информацию.

---

## Задание 3. Второй наследник

1. Создать класс `Teacher`, наследующий `Person`.
2. Поле:
   * предмет.
3. Вывести данные.

---

## Задание 4. Класс «Транспорт»

1. Базовый класс `Transport`:
   * поле: скорость.
2. Производный класс `Car`:
   * поле: марка.
3. Вывести данные.

---

## Задание 5. Анализ кода

Дан код:

```cpp
class A {
public:
    int x;
};

class B : A {
#public:
    int y;
};

int main() {
    B b;
    b.x = 5;
}
```

Нужно:
* найти ошибку;
* исправить код;
* объяснить причину ошибки.
