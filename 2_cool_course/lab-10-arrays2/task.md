# Лабораторная работа №10

## Работа с матрицами (C++)

---

## Вариант

Единый для всех студентов

---

## Цель работы

Научиться работать с двумерными массивами:
* вводить элементы матрицы;
* выводить матрицу;
* выполнять обработку строк и элементов.

---

## Задание 1. Ввод и вывод матрицы

1. Создать матрицу размером **$3 \times 3$**.
2. Ввести элементы матрицы с клавиатуры.
3. Вывести матрицу в виде таблицы.

---

## Задание 2. Сумма элементов

1. Найти сумму всех элементов матрицы.
2. Вывести результат.

---

## Задание 3. Максимальный элемент

1. Найти максимальный элемент матрицы.
2. Вывести его значение.

---

## Задание 4. Сумма главной диагонали

1. Найти сумму элементов главной диагонали.
2. Вывести результат.

**Подсказка:** `i == j`.

---

## Задание 5. Анализ ошибки

Дан код:

```cpp
int a[3][3];

for (int i = 0; i <= 3; i++) {
    for (int j = 0; j <= 3; j++) {
        cin >> a[i][j];
    }
}
```

* Найти ошибку.
* Исправить код.
* Объяснить, почему возникает ошибка.
