## Понятие двумерного массива

**Двумерный массив** — это таблица элементов одинакового типа.

Пример таблицы:

|   |   |   |
|---|---|---|
| 1 | 2 | 3 |
| 4 | 5 | 6 |
| 7 | 8 | 9 |

У каждого элемента есть **два индекса**:
* номер строки;
* номер столбца.

В C++ индексация начинается **с 0**.

---

## Объявление двумерного массива

Общий вид:

```cpp
тип имя[строки][столбцы];
```

Пример:

```cpp
int a[3][3];
```

Создаётся матрица $3 \times 3$.

### Доступ к элементам

```cpp
a[0][0] = 5;
a[1][2] = 10;
```

Первый индекс — строка, второй — столбец.

### Ввод элементов матрицы

Для работы с матрицами используют вложенные циклы.

```cpp
int a[3][3];

for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        cin >> a[i][j];
    }
}
```

### Вывод матрицы

```cpp
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        cout << a[i][j] << " ";
    }
    cout << endl;
}
```

### Обработка матриц

С матрицами выполняют различные операции:
* поиск максимального элемента;
* вычисление суммы элементов;
* обработка строк или столбцов;
* работа с главной диагональю.

#### Главная диагональ

Главная диагональ — элементы:
* `a[0][0]`;
* `a[1][1]`;
* `a[2][2]`.

Условие: `i == j`.

Пример:
```cpp
sum += a[i][i];
```

### Типичные ошибки
* неверные границы циклов;
* перепутаны индексы строки и столбца;
* выход за границы массива;
* использование одного цикла вместо вложенных.
