# Лабораторная работа №8

## Циклические программы (C++)

---


## Цель работы

Научиться создавать программы с использованием циклов:
* `while`
* `for`

---

## Задание 1. Вывод чисел

1. Вывести все целые числа от 1 до 10.
2. Использовать цикл `for`.

---

## Задание 2. Сумма чисел

1. Найти сумму всех целых чисел от 1 до 100.
2. Использовать цикл `for`.
3. Вывести результат.

---

## Задание 3. Таблица умножения

1. Ввести целое число `n`.
2. Вывести таблицу умножения для числа `n` от 1 до 10.
3. Использовать цикл `while`.

---

## Задание 4. Подсчёт положительных чисел

1. Вводить целые числа, пока не будет введено число `0`.
2. Подсчитать количество положительных чисел.
3. Использовать цикл `while`.

---

## Задание 5. Анализ цикла

Дан фрагмент кода:

```cpp
int i = 1;

while (i <= 10) {
    cout << i << " ";
}
```

* Определить ошибку.
* Исправить код.
* Объяснить, что произойдёт при выполнении программы без исправления.

---
