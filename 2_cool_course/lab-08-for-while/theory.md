## Понятие цикла

**Цикл** — это конструкция, позволяющая выполнять один и тот же участок кода несколько раз.

Циклы применяются, когда:
* известно количество повторений;
* нужно обрабатывать набор данных;
* необходимо выполнять действие до выполнения условия.

---

## Цикл `while`

Цикл с **предусловием** — сначала проверяется условие, затем выполняется тело цикла.

Общий вид:

```cpp
while (условие) {
    // тело цикла
}
```

Если условие сразу ложно — цикл не выполнится ни разу.

**Пример `while`:**

```cpp
int i = 1;

while (i <= 5) {
    cout << i << " ";
    i++;
}
```

**Результат:**

```
1 2 3 4 5
```

---

## Цикл `for`

Цикл с параметром, используется, когда известно количество повторений.

Общий вид:

```cpp
for (начало; условие; шаг) {
    // тело цикла
}
```

**Пример `for`:**

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
```

---

## Счётчик цикла

Счётчик — переменная, которая:
* изменяется при каждом повторении;
* управляет завершением цикла.

**Пример:**

```cpp
int sum = 0;

for (int i = 1; i <= 10; i++) {
    sum += i;
}
```

---

## Типичные ошибки

* Отсутствие изменения счётчика.
* Неверное условие завершения.
* Бесконечный цикл.
* Ошибка на 1 (лишний или недостающий повтор).

**Бесконечный цикл:**

```cpp
while (true) {
    cout << "Ошибка!";
}
```

Использовать только осознанно.
