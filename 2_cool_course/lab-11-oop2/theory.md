# Лабораторная работа №12

## Наследование в языке C++

---

## Цель работы

Познакомиться с понятием наследования и научиться:
* создавать базовые и производные классы;
* наследовать поля и методы;
* понимать, зачем нужно наследование.

---

## Что такое наследование?

**Наследование** — это механизм, при котором один класс может использовать свойства и методы другого класса.

---

## Пример из жизни

* Класс: «Животное».
* Подклассы:
  * «Кошка»;
  * «Собака».

У всех есть:
* имя;
* возраст.

---

## Базовый (родительский) класс

```cpp
class Animal {
public:
    string name;
};
```

## Производный класс

```cpp
class Dog : public Animal {
public:
    string breed;
};
```

## Использование

```cpp
Dog d;

d.name = "Bobik";   // из базового класса
d.breed = "Husky"; // своё поле
```

## Добавление методов

```cpp
class Animal {
public:
    string name;

    void show() {
        cout << name << endl;
    }
};
```

## Переиспользование метода

```cpp
Dog d;
d.name = "Bobik";
d.show();
```

---

## Зачем нужно наследование?

* избегать дублирования кода;
* упрощать структуру программы;
* логически объединять объекты.

---

## Типичные ошибки

* забывают `public` при наследовании;
* путают базовый и производный класс;
* пытаются использовать несуществующие поля;
* не понимают, откуда берётся поле.

---

## Важно

На данном этапе:
* используем только `public`;
* не используем сложные темы (`virtual`, `override` и т. д.).

---

## Вывод

Наследование позволяет:
* расширять классы;
* повторно использовать код;
* строить иерархию объектов.
