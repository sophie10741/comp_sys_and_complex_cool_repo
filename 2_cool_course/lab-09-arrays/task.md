# Лабораторная работа №9

## Обработка одномерных массивов (C++)

---

## Цель работы

Научиться работать с одномерными массивами:
* создавать массивы;
* вводить и выводить элементы;
* выполнять обработку данных.

---

## Задание 1. Ввод и вывод массива

1. Создать массив из 5 целых чисел.
2. Ввести элементы массива с клавиатуры.
3. Вывести массив на экран.

---

## Задание 2. Сумма элементов

1. Найти сумму всех элементов массива.
2. Вывести результат.

---

## Задание 3. Максимальный элемент

1. Найти максимальный элемент массива.
2. Вывести его значение.

---

## Задание 4. Подсчёт элементов по условию

1. Подсчитать количество положительных элементов массива.
2. Вывести результат.

---

## Задание 5. Анализ ошибки

Дан код:

```cpp
int a[5];

for (int i = 1; i <= 5; i++) {
    cin >> a[i];
}
```

* Найти ошибку.
* Исправить код.
* Объяснить, почему возникает ошибка.
