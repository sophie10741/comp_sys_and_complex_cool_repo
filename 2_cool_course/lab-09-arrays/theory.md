# Лабораторная работа №9

## Одномерные массивы в языке C++

---

## Цель работы

Изучить понятие массива и научиться:
* объявлять одномерные массивы;
* заполнять массивы с помощью циклов;
* обрабатывать элементы массива;
* находить сумму, максимум, количество элементов по условию.

---

## Понятие массива

**Массив** — это набор однотипных элементов, расположенных в памяти подряд и имеющих общее имя.

Каждый элемент массива имеет **индекс**.

Индексация в C++ начинается с **0**.

---

## Объявление массива

Общий вид:

```cpp
тип имя_массива[размер];
```

**Пример:**

```cpp
int a[5];
```

Массив `a` содержит 5 целых чисел с индексами от 0 до 4.

---

## Доступ к элементам массива

```cpp
a[0] = 10;
a[1] = 20;
```

**Чтение элемента:**

```cpp
cout << a[0];
```

---

## Заполнение массива с клавиатуры

Чаще всего используется цикл `for`:

```cpp
int a[5];

for (int i = 0; i < 5; i++) {
    cin >> a[i];
}
```

---

## Вывод массива

```cpp
for (int i = 0; i < 5; i++) {
    cout << a[i] << " ";
}
```

---

## Обработка массива

С массивами часто выполняют:
* подсчёт суммы элементов;
* поиск максимального или минимального значения;
* подсчёт элементов по условию.

**Пример — сумма элементов:**

```cpp
int sum = 0;

for (int i = 0; i < 5; i++) {
    sum += a[i];
}
```

---

## Типичные ошибки

* Выход за границы массива.
* Использование неверного индекса.
* Отсутствие цикла при обработке.
* Неправильный размер массива.

---

## Вывод

Массивы позволяют:
* хранить несколько значений под одним именем;
* удобно обрабатывать данные с помощью циклов;
* упрощать программы.
