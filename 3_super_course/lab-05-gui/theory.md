# Лабораторная работа №5  
## GUI-приложения на Java (Swing)

---

## 1. Зачем нужен GUI

До этого момента мы писали **консольные приложения**.  
Они отлично подходят для изучения логики, алгоритмов и структуры программ,  
но **реальные пользовательские приложения почти всегда имеют графический интерфейс**.

GUI (Graphical User Interface) позволяет:
- взаимодействовать с программой без командной строки;
- вводить данные через формы;
- получать результат в наглядном виде;
- работать с событиями (кнопки, клики, ввод текста).

В этой лабораторной работе мы переходим от *«программа → вывод в консоль»*  
к *«приложение → пользователь → события»*.

---

## 2. Архитектура GUI-приложений

GUI-программа **не работает линейно**, как консольная.

### Консольное приложение:
1. Программа запускается
2. Выполняется код сверху вниз
3. Программа завершается

### GUI-приложение:
1. Создаётся окно
2. Программа **ожидает действий пользователя**
3. Код выполняется **в ответ на события**

> ❗ GUI-программа живёт, пока работает окно.

---

## 3. Swing — библиотека для GUI в Java

Swing — стандартная библиотека Java для создания оконных приложений.

Плюсы:
- встроена в JDK
- работает на любой ОС
- не требует дополнительных библиотек

Основные классы:
- `JFrame` — окно
- `JPanel` — контейнер
- `JButton` — кнопка
- `JLabel` — текст
- `JTextField` — поле ввода
- `JTextArea` — многострочный текст

---

## 4. Минимальное окно Swing

```java
import javax.swing.*;

public class Main {
    public static void main(String[] args) {
        JFrame frame = new JFrame("Моё первое окно");

        frame.setSize(400, 300);
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.setVisible(true);
    }
}
````

### Что здесь происходит:

* создаётся объект `JFrame`
* задаётся размер окна
* указывается поведение при закрытии
* окно становится видимым

---

## 5. Контейнеры и компоновка (Layout)

GUI состоит из компонентов, которые **располагаются внутри контейнеров**.

### Основные Layout-менеджеры:

* `FlowLayout` — по порядку
* `BorderLayout` — по областям
* `GridLayout` — таблица

Пример `FlowLayout`:

```java
frame.setLayout(new FlowLayout());
frame.add(new JButton("Кнопка 1"));
frame.add(new JButton("Кнопка 2"));
```

---

## 6. Панели (`JPanel`)

`JPanel` используется для:

* логического разделения интерфейса
* группировки элементов
* создания сложных интерфейсов

```java
JPanel panel = new JPanel();
panel.add(new JLabel("Имя:"));
panel.add(new JTextField(10));

frame.add(panel);
```

---

## 7. События и обработчики

GUI-приложение реагирует на **события**:

* нажатие кнопки
* ввод текста
* закрытие окна

### Пример обработки нажатия кнопки:

```java
JButton button = new JButton("Нажми меня");

button.addActionListener(e -> {
    System.out.println("Кнопка нажата");
});
```

Это **ключевая идея GUI**:

> код выполняется **только когда происходит событие**

---

## 8. Получение данных из полей ввода

```java
JTextField textField = new JTextField(15);

button.addActionListener(e -> {
    String text = textField.getText();
    System.out.println("Введено: " + text);
});
```

---

## 9. Проверка и валидация данных

Пользователь может:

* ничего не ввести
* ввести некорректные данные
* ввести текст вместо числа

Пример простой проверки:

```java
try {
    int value = Integer.parseInt(textField.getText());
    System.out.println("Число: " + value);
} catch (NumberFormatException ex) {
    JOptionPane.showMessageDialog(frame, "Введите число!");
}
```

---

## 10. Диалоговые окна (`JOptionPane`)

```java
JOptionPane.showMessageDialog(frame, "Ошибка ввода");
```

Используются для:

* ошибок
* уведомлений
* подтверждений действий

---

## 11. Разделение логики и интерфейса

❌ Плохо:

* вся логика внутри обработчика кнопки

✅ Хорошо:

* GUI отвечает за интерфейс
* логика вынесена в отдельные классы

Пример:

```java
public class Calculator {
    public int sum(int a, int b) {
        return a + b;
    }
}
```

GUI только вызывает методы.
