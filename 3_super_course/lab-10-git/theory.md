# Что такое система контроля версий (VCS)

**Система контроля версий (Version Control System, VCS)** — это инструмент, который позволяет:

- отслеживать изменения в коде;
- сохранять историю изменений;
- возвращаться к предыдущим версиям;
- работать в команде.

---

# Зачем нужен Git

Представим ситуацию:

Вы написали программу → всё работает.  
Потом внесли изменения → всё сломалось.  

Как вернуть старую версию?

Без Git — почти никак.  
С Git — 1 команда.

---

# Основные возможности Git

- хранение истории изменений;
- работа с версиями проекта;
- параллельная разработка (ветки);
- командная работа;
- резервное копирование кода.

---

# Что такое GitHub

**GitHub** — это онлайн‑сервис для хранения Git‑репозиториев.

Он позволяет:

- хранить код в интернете;
- делиться проектами;
- работать в команде;
- просматривать изменения.

---

# Основные понятия

## Репозиторий (repository)

Папка с проектом, которая отслеживается Git.

---

## Коммит (commit)

Сохранение изменений.

Можно представить как «снимок проекта».

---

## Ветка (branch)

Отдельная линия разработки.

---

## push

Отправка изменений на GitHub.

---

## pull

Получение изменений с GitHub.

---

# Работа через веб‑интерфейс GitHub

## Создание аккаунта

1. Перейти на сайт: https://github.com.
2. Нажать **Sign up**.
3. Заполнить данные.

---

## Создание репозитория

1. Нажать **New repository**.
2. Ввести название.
3. Выбрать Public.
4. Нажать **Create repository**.

---

## Загрузка файлов через веб

1. Открыть репозиторий.
2. Нажать **Add file → Upload files**.
3. Перетащить файлы.
4. Нажать **Commit changes**.

---

# Работа через консоль (самое важное)

## 1. Инициализация Git

```bash
git init
```

Создаёт Git‑репозиторий в папке.

## 2. Добавление файлов

```bash
git add .
```

Добавляет все файлы в отслеживание.

## 3. Коммит

```bash
git commit -m "Первый коммит"
```

Сохраняет изменения.

## 4. Связь с GitHub

```bash
git remote add origin https://github.com/USERNAME/REPO.git
```

## 5. Отправка на GitHub

```bash
git push -u origin main
```

## Полный пример

```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/username/project.git
git push -u origin main
```
