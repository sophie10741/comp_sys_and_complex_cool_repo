# Лабораторная работа №9
# Разработка многостраничного веб‑сайта на Java Spring Boot

---

## Цель работы

Разработать полноценное многостраничное веб‑приложение на Java с использованием Spring Boot, HTML, CSS и Thymeleaf.

---

## Задачи работы

В ходе выполнения лабораторной работы студент должен:

- создать Spring Boot проект;
- реализовать маршрутизацию страниц;
- создать несколько HTML‑страниц;
- реализовать навигацию;
- подключить CSS;
- оформить интерфейс;
- передавать данные из Java в HTML;
- создать динамические элементы;
- оформить проект в едином стиле.

---

## Технологии

Обязательно использовать:

- Java;
- Spring Boot;
- Maven;
- HTML;
- CSS;
- Thymeleaf.

## Тематика сайта

Тема сайта — свободная.

- сайт игровой студии;
- сайт музыкальной группы;
- сайт Linux‑дистрибутивов;
- сайт кафе;
- сайт про фильмы;
- сайт про компьютерные комплектующие;
- сайт по Minecraft;
- сайт киберспортивной команды;
- сайт учебного проекта;
- сайт путешествий.

## Основные требования

### 1. Структура сайта

Сайт должен содержать минимум:

- 4 страницы;
- меню навигации;
- единый дизайн.

#### Обязательные страницы

**Главная**

Содержит:

- название сайта;
- краткое описание;
- изображение или баннер;
- приветственный текст.

---

**О проекте**

Содержит:

- информацию о тематике сайта;
- описание проекта;
- преимущества/особенности.

---

**Галерея / Каталог / Новости**

Содержит:

- карточки;
- изображения;
- блоки информации.

---

**Контакты**

Содержит:

- форму;
- контакты;
- ссылки.

---

### 2. Навигация

На каждой странице должно быть меню.

**Пример:**

```text
Главная | О проекте | Галерея | Контакты
```

---

### 3. CSS‑оформление

Обязательно использовать:

- фон;
- цвета;
- отступы;
- стили кнопок;
- стили текста;
- оформление блоков.

---

### 4. Использование Thymeleaf

Необходимо минимум:

- 3 переменные из Java;
- вывод данных через `th:text`.

**Пример**

*Java:*
```java
model.addAttribute("title", "Linux World");
```

*HTML:*
```html
<h1 th:text="${title}"></h1>
```

---

### 5. Формы

Необходимо создать минимум одну HTML‑форму.

**Примеры:**

- форма обратной связи;
- регистрация;
- комментарий;
- отзыв.

---

### 6. Java‑код

Обязательно:

- минимум 1 Controller;
- минимум 4 маршрута;
- корректная структура проекта.

---

### 7. Дополнительные элементы

Необходимо реализовать минимум 3 элемента:

- карточки;

- кнопки;
- списки;
- hover‑эффекты;
- анимации;
