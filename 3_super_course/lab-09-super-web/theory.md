## Как работает веб‑приложение

### Схема работы

```text
Пользователь → Браузер → Сервер → Java‑приложение → Ответ HTML → Браузер
```

**Пример**

Пользователь открывает:

```
http://localhost:8080/about
```

Сервер получает запрос:

```
GET /about
```

Java‑приложение обрабатывает запрос и отправляет HTML‑страницу.

### Что такое Spring Boot

Spring Boot — это фреймворк для создания Java‑приложений.

Он позволяет:

- быстро запускать сервер;
- создавать сайты;
- писать API;
- подключать базы данных;
- работать с HTML‑страницами.

### Преимущества Spring Boot

- простая настройка;
- встроенный сервер;
- современная архитектура;
- удобная работа с маршрутами;
- популярность в индустрии.

### Контроллеры

Контроллер принимает запросы от браузера.

**Пример контроллера**

```java
package com.example.demo.controller;

import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.GetMapping;

@Controller
public class PageController {

    @GetMapping("/")
    public String index() {
        return "index";
    }

    @GetMapping("/about")
    public String about() {
        return "about";
    }
}
```

#### Разбор кода

**Аннотация `@Controller`**

```java
@Controller
```

Говорит Spring: «Этот класс отвечает за страницы сайта».

**Аннотация `@GetMapping`**

```java
@GetMapping("/about")
```

Означает: «Если пользователь откроет `/about`, вызвать этот метод».

**Возврат строки**

```java
return "about";
```

Spring ищет файл: `templates/about.html`.

### HTML

HTML — язык разметки веб‑страниц.

**Пример страницы**

```html
<!DOCTYPE html>
<html>
<head>
    <title>Главная</title>
</head>
<body>

<h1>Мой сайт</h1>

<p>Добро пожаловать!</p>

</body>
</html>
```

**Основные HTML‑теги**

| Тег | Назначение |
|----|-----------|
| `h1` | Заголовок |
| `p` | Текст |
| `a` | Ссылка |
| `img` | Изображение |
| `div` | Блок |
| `ul` | Список |
| `button` | Кнопка |

**Ссылки между страницами**

```html
<a href="/about">О нас</a>
```

### Thymeleaf

Thymeleaf — шаблонизатор для Java.

Позволяет:

- вставлять данные из Java;
- создавать динамические страницы.

**Передача данных из Java в HTML**

*Контроллер*

```java
@GetMapping("/")
public String index(Model model) {
    model.addAttribute("title", "Мой сайт");
    return "index";
}
```

*HTML*

```html
<h1 th:text="${title}"></h1>
```

| Метод | Назначение |
|-------|-----------|
| GET | Получение данных |
| POST | Отправка данных |

**Пример GET‑запроса**

### Формы

Формы позволяют отправлять данные.

**Пример формы**

```html
<form action="/send" method="post">
    <input type="text" name="username">
    <button>Отправить</button>
</form>
```

**Пример обработки формы**

```java
@PostMapping("/send")
public String send(String username) {
    System.out.println(username);
    return "index";
}
```

### Рекомендации по структуре сайта

Хороший сайт должен:

- иметь единый стиль;
- содержать навигацию;
- быть понятным;
- иметь аккуратный интерфейс;
- корректно отображаться.

**Что НЕ рекомендуется:**

- огромный текст без структуры;
- отсутствие меню;
- плохие цвета;
- отсутствие CSS;
- копирование чужого сайта;
- хаотичное размещение элементов.

**Пример хорошей структуры сайта:**

- Главная;
- О проекте;
- Галерея;
- Контакты;
- FAQ.
